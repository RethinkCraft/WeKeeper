# WeKeeper 0.7.0

保留云端看板、消息同步、私人 AI 问答和协议群机器人。删除每 30 分钟自动总结，以及旧 UI 机器人、pilot 和专属实验链路。用户主动提问或要求 AI 总结仍可使用。

- 统一协议机器人的检查与运行入口，接通云端配置和状态管理。
- 独立保存共享授权和额度暂停状态，保留实际用量记录。
- 公共归档存储兼容现有 schema 4/5，桥接保留来源身份、消息编号与消费水位。
- 更新中英文 README、通用部署模板、完整网关补丁链和升级文档。

## 升级说明

先升级本机生产者、停止总结上传，再升级云端至 schema 3；最后以当前有效本机配置对齐云端并启用管理。自动总结内容会删除，不新增备份，也不在回退时恢复。保持现有账号、队列和游标，不重新激活消费边界；回退必须使用支持目标数据库结构的兼容版本。完整步骤见 [upgrading](https://github.com/RethinkCraft/WeKeeper/blob/v0.7.0/docs/upgrading.md)。

## 验证状态

干净源码包通过 2160 项 Python 测试、19 项前端测试和生产构建。独立 wheel 安装、三个 CLI、15 个归档 MCP 工具及 20 个网关补丁校验均通过。已完成本机及云端服务健康检查、连续同步、真实私人 AI 问答和配置下发确认。

2026-11-06 最终实机验收通过：原绑定测试群新增 3 条独立 @ 请求，每条各对应一条已受理回复，引用目标、归档及云端同步记录一致，真实用量完整记账。用户确认手机端只收到一条对应回复且引用能跳回原消息；业务进程正常重启后，已完成请求的回复、发送和用量记录均未增加，消费水位未回退。网关持续接收，服务运行正常。
